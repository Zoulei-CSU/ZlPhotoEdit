# ZlPhotoEdit（逐鹿 图片编辑器）

[English](README_en.md) | 中文

一个基于 Qt 的自用轻量级图片编辑器。**纯 Qt 实现，零第三方依赖。**

## 为什么写它

Photoshop 太重了。我只是偶尔 P 一下图，为一两次调整去装一个几个 GB 的软件、每次等它慢慢启动，
实在不划算 —— 于是花时间自己写了一个。

目标很朴素：**打开快、功能够用、体量小**。主程序（不含 Qt 库）**不到 2 MB**，
双击即开，没有安装过程、没有后台服务、没有联网。

*多图层工作区：左侧工具箱、中间画布（可开标尺 / 参考线 / 网格）、右侧图层面板（混合模式 + 不透明度 +
历史记录 + 颜色面板）、底部状态栏（坐标 / 尺寸 / 缩放 / 取样色）。*

拖动参数时在降采样副本上实时预览，确定前完全不碰原图。*

## 功能

### 图层

- 多图层，22 种混合模式 + 不透明度 + 可见性控制
- 图层面板：行内自绘（缩略图 / 名字 / 混合模式·不透明度 / 眼睛 / 锁）、拖拽排序、多选
- 双击或 F2 重命名；上移 / 下移 / 向下合并 / 合并可见 / 拼合 / 复制 / 删除
- 缩略图 300ms 节流刷新

### 选区

- 矩形 / 椭圆选框，支持**添加、减去、交集**（`Shift` / `Alt` / `Shift+Alt`）
- **羽化**与抗锯齿；`Shift` 约束正方形、`Alt` 以起点为中心
- **魔术棒**：按相似颜色一键成选区，可选**连续 / 非连续**、判据取合成图或仅当前图层
- 蚂蚁线（黑底 + 白虚线，相位动画推进）
- 全选 / 取消选择 / 反选

### 绘制工具（15 个）

| 工具 | 说明 |
| --- | --- |
| 移动 | 拖动平移图层；`Shift` 约束方向，`Alt` 复制式拖动，方向键微调 |
| 画笔 | 大小 1~500、硬度 0~100、不透明度、流量；笔刷轮廓跟随鼠标 |
| 橡皮 | 擦除到透明，与画笔共用参数分组 |
| 矩形选框 / 椭圆选框 | 见上「选区」 |
| 油漆桶 | 扫描线种子填充；容差 0~255（欧氏色差）、抗锯齿过渡带、连续 / 非连续 |
| 吸管 | 取**合成图**颜色（所见即所得）；点 / 3×3 / 5×5 平均；`Alt` 取背景色 |
| 魔术棒 | 见上「选区」 |
| 直线 | `Shift` 吸附 8 方向 |
| 矩形 / 椭圆 | `Shift` 拖成正方形 / 正圆；前景色 = 线色，背景色 = 填充色 |
| 文字 | 单击开出输入浮层，`Ctrl+Enter` 确认 / `Esc` 取消；字体 / 字号 / 颜色 / 粗斜体 / 下划线 / 对齐 / 行距 / 字间距 |
| 裁剪 | 拖框裁剪，框外实时压暗、构图网格、8 枚角柄、比例预设（自由 / 1:1 / 4:3 / 16:9 / 9:16） |
| 抓手 | 左键拖动平移画布，光标两态；也可按住空格临时平移 |
| 缩放 | 点按放大 / `Alt` 点按缩小；拖框把框住区域铺满视口 |

### 调整与滤镜

- **亮度 / 对比度**：双滑块，两个参数合成一条 LUT 后一次查表
- **色相 / 饱和度**：色相 ±180°、饱和度 / 明度 ±100，三参数一次算完
- **曲线**：RGB + 红 / 绿 / 蓝四条曲线叠乘，12 种预设，控制点可增删拖动
- **色阶**：输入黑 / 白场 + 灰度系数 + 输出黑 / 白场，直方图下三枚手柄可拖，带「自动」
- 锐化、模糊、去色、反色
- 调整类对话框统一走**降采样预览**（最长边 1024），拖动最快 60fps，取消零成本

### 尺寸与几何

- **图像大小**：像素缩放 + 重采样（最近邻 / 双线性 / 自实现 bicubic / Lanczos）；像素或百分比输入
- **画布大小**：不重采样，只改容器；九宫格锚点 + 扩展色；缩小时智能适配；像素或百分比输入
- **旋转**：90° 倍数（无损）/ 任意角度（画布按包围盒自动扩大、内容不裁）
- **翻转**：水平 / 垂直
- **裁剪**：工具交互裁剪，或「图像 → 裁剪」一键裁到选区包围盒
- **缩放**：基于视图矩阵，支持适配窗口 / 实际大小 / 预设级别

### 文件与剪贴板

- 新建 / 打开 / **打开为图层**（把另一张图整幅变成本文档的一个新图层）/ 保存 / 另存为
- 格式：BMP / GIF / **ICO（自写编码器）** / JPEG / PNG / SVG / TGA / TIFF / WBMP / WebP
- **另存为 ICO**：`≤512` 硬上限，超限拒绝并说明原因（不用 Qt 的 qico —— 它会把 300×300 静默缩到 256）
- 打开时按 **EXIF** 自动摆正
- 复选 / 剪切 / 粘贴选区，与系统剪贴板双向兼容；粘贴为新图层 / 粘贴到当前图层
- 未保存提示；命令行多参数或拖入多个文件都开成多页

### 多标签页

- 同时打开多个文档，**每页各有自己的文档 + 撤销栈 + 视图状态**（缩放 / 平移互不干扰）
- 标签带 `×` 与未保存标记（`*`）；关窗口时逐页询问未保存内容

### 视图辅助

- **标尺**：上方 / 左侧，单位可切 **px / cm / mm / inch / pt**
- **参考线**：从标尺拖出、可拖动 / 锁定 / 清除
- **网格**：间距（预设 8/16/32/64/128/256 + 自定义 4~2000）、线色、**对齐吸附**
- 三者均为**视图辅助，结构上不进导出图像**
- 导航器面板；状态栏显示坐标 / 图像尺寸 / 缩放比例 / 取样色 / 撤销栈占用

### 屏幕截图

- 「文件 → 屏幕截图」：**立即截图** / **延迟 3 / 5 / 10 秒**
- 立即截图另挂**全局快捷键 `Ctrl+Alt+S`** —— 程序最小化时照样能按
- 截取光标所在屏，结果开成**一页内存文档**（不落盘）

### 撤销重做

- 基于 `QUndoStack`，撤销上限 30 步，历史面板可点击跳转
- 画笔 / 形状按**脏矩形**失效、整笔一条；滤镜 / 调整 / 变换 / 裁剪按**整层快照**

### 平台适配

- 高 DPI 缩放
- 内存降级与错误处理

## 构建与运行

```bash
# 0) 环境：Qt 5.15.x（MSVC 构建）+ Visual Studio 2022；Git Bash 里先补好编译器环境
source build_env.sh

# 1) 构建 —— 方式一：qmake（与 Qt Creator 一致）
mkdir -p build && cd build && qmake ../ZlPhotoEdit.pro -spec win32-msvc "CONFIG+=release" && nmake -nologo

# 1) 构建 —— 方式二：CMake + Ninja
cmake -S . -B build_cmake -G Ninja -DCMAKE_BUILD_TYPE=Release && cmake --build build_cmake

# 2) 运行
./build/release/ZlPhotoEdit.exe          # qmake 产物
./build_cmake/bin/ZlPhotoEdit.exe        # CMake 产物
```

环境要求、两种构建方式的细节、构建陷阱、发布打包与目录结构，全部在
[**docs/构建与运行.md**](docs/构建与运行.md)。

## 命名与图标

> **程序名**：中文 **逐鹿 图片编辑器**，英文 **ZlPhotoEdit**，都出自 `src/ui/AppInfo.h`，
> 窗口标题、任务栏、「关于」框、退出提示一律从它取，代码里不再出现程序名字面量。
>
> ★ **英文名同时是 QSettings 的存储路径**（注册表 `HKCU\Software\ZlStudio\ZlPhotoEdit`），
> 一旦发布就不能改 —— 改了等于把用户全部设置重置。
>
> **图标**分两层，都由同一张 `logo` 提供：窗口 / 任务栏图标走 `resources/logo.svg` → qrc；
> exe 文件本身的图标走 `resources/logo.ico` → `resources/app.rc` → PE 资源段（运行时改不了）。
