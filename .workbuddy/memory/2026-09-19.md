## 回出的真 bug / 踩坑

1. **qrc 前缀是"拼接"不是"替换"**：`prefix="/icons"` + `<file>icons/x.svg`
   得到 `:/icons/icons/x.svg`。`rcc --list` **看不出**这个错，首跑 `icon_test`
   63 个图标全部报"文件不存在"才暴露。→ 改 `prefix="/"`。
2. **`.pro` 不能有 BOM**：`qmake` 直接拒读 `Unexpected UTF-8 BOM`。
   与"源文件必须有 BOM"正好相反，是本轮新增的第 4 条构建铁律。
3. **`QIcon(":/x.svg")` 是陷阱**：缺 `qsvg` 插件时它**不报错**，只给你一个
   "合法但永远画不出东西"的空 QIcon。→ 改显式 `QSvgRenderer` + `isValid()`。
4. **截图工程漏 `QT += svg`** → `C1083: 找不到 QSvgRenderer`。这是好事（编译期露脸）。
5. **`flip_h` / `flip_v` 在 16px 下长得一模一样** —— 断言全部合格，**只有菜单截图
   看出来**。两个浅色三角形糊成一团、把中轴盖住。改法：三角形放大到几乎顶满 +
   **一深一浅**（深浅对比 + 中轴方向两个维度同时区分）。
6. **接触表又抓出三个"像不像"问题**：`help_qt` 画成放大镜（和 `view_zoom_in` 撞形）、
   `tool_eraser` 像菱形、`color_swap` 挤成一坨。
7. **植入变体选错**：第一次植入写 `rect x=-4 y=-4 w=32 h=32` 且 `fill="none"` ——
   整框在视框外又没填充，**画出来真的是空白**，于是报的是"空白"而不是"触边"。
   → **植入必须朝着你想验证的那条断言去设计**。

## ★ 自检脚本"防假绿"改法（重要）★

`run_tests.sh` 原来靠 `rm -f 旧产物` 防"编译失败伪装成通过"。但 `rm` 依赖
"允许删除"这个前提 —— 受限环境里批量删除会被安全策略整体拦截，**整条流水线当场停摆**
（本轮实测触发 `SAFE_DELETE_BULK_CONFIRM_REQUIRED`，累计 222 次）。

改成**比对产物 mtime 是否变新**，并且**不删任何东西**：

```
file_mtime()   取修改时间（不存在给 0）
require_fresh() ①存在 ②mtime 必须变新，否则判失败并打印日志
```

适用范围：`exe` / `moc_*.cpp` / `qrc_resources.cpp` 三处。
`rm` 只是"事后无法伪装"，**mtime 是"当场识破"**，而且更严格：
它还覆盖"工具报成功但内容其实是上一版（文件被进程锁住没覆盖）"。
→ 顺带删掉了临时产物 `.run_tests_nodel.sh` 与 `make_nodel_only.py`。

## ★ 抓住两个真 bug（都在 `Document`，不在面板）★

1. **`mergeLayerDown()` 方向写反**：原来 `upper = layer(index+1)`、
   `lower = layer(index)` —— 把**下面那层合到上面去**了。画面差异不大，
   但"哪一层的属性被保留"全错。顺手修掉一个隐含错误：下层的不透明度
   原先没烘进结果（改为先把下层按其不透明度合成到透明底，结果层回 100% / Normal）。
2. **`mergeVisibleLayers()` 的落点算在错误的时刻**：结果层应插在
   "原可见层里最靠下的那一层"的位置，但实现是在**删掉所有可见层之后**
   才用旧 `insertAt` 数隐藏层 —— 索引已经偏了，结果层落在错误槽位。
   → 把计数移到删除**之前**。（第一版修复仍错，被 mainwin 当场又抓出一次。）

两条都是"数学看着对、结果全错"的形态，靠 `mainwin_test` 的**不变式**断言
（不是写死某个层序）抓到。

## 踩过的坑

1. ★ **通用兜底分支吞掉了专用分支** ★：`shot` 用"mode 名 → 菜单动作名"
   （`levels` → `actionLevels`）的通用兜底处理对话框截图。它写在 `layers`
   专用分支**之前**，于是 `layers` 被先吃掉，去找并不存在的 `actionLayers`
   报"找不到动作" —— 而真正的分支就在下面躺着。
   → 在兜底里加**保留模式表** `kReservedModes`，**新增专用模式时必须同步它**。
2. ★ **offscreen 平台没有字体** ★：Qt 5 起不随包分发字体。`layer_panel_test`
   要量"隐藏行名字变淡"，文字画成空白后前后两张图完全一样 → 断言莫名红。
   → `main()` 里设 `QT_QPA_FONTDIR=C:/Windows/Fonts`（仅当目录存在）。
3. **节流 ≠ 防抖**：缩略图刷新写成 `restart()` 的话，连续画时计时器永远不到期，
   缩略图在停笔前一直不刷。正确写法是 `if (!isActive()) start();`。
   断言方式：连打 20 次 `contentChanged`，渲染计数增量必须 ≤ 1。
   量之前要先 `setThrottleIntervalMs(60000)` **清干净计时器**，否则读到上次残留（假绿）。
4. **`action_check.py` 的孤儿误报**：`layer_visible/hidden/lock/unlock/blend/opacity`
   是以**三元字符串字面量**被引用的，原脚本只扫 `icons::icon()` → 判成孤儿，
   而"孤儿"的建议动作是"删掉它" —— 照做则**眼睛和锁静默消失**。
   → 图标引用拆 `referenced_hard`（参与"文件不存在"错误判定）与
   `referenced_soft`（参与"孤儿"警告判定）。
5. **`QList<T>` 陷阱复现**：`Document::layers().mutableAll()` 返回的容器
   按下标改名字时要用 `QList::operator[]`，不要指望 `data()`。

## ★ 抓出两个潜伏已久的公用代码真 bug ★

1. **`DrawCommand` 描边编号撞号（最严重）**：旧构造函数用 `m_strokeId(currentStrokeId())`，
   而 `currentStrokeId()` 返回 `g_strokeCounter-1` —— 计数器**从没被 `beginStroke()` 推过**
   （全工程无人调用 `beginStroke`），于是**常量 0**。所有命令 `id()` 全同 →
   `QUndoStack` 静默 `mergeWith()` 合并 → 两次点击只留一条撤销记录。**画笔同理"画两笔算一步"。**
   编译 / 运行 / 其余自检全绿、零提示。
   → 构造函数改**必填 `int strokeId`**，新增具名工厂 `DrawCommand::standalone(...)`
   （内部取新号），**删掉 `currentStrokeId()`**；`BucketTool` / `BrushTool` 两处调用改走工厂。
2. **`Blend::compositeLayer` 写回时二次预乘**：旧码 `finalR = mixR * finalA`，
   但 `mixR` **已经是预乘量**（推导：`Co·Ao = Sr·Sa + Dr·Da·(1-Sa)`，右侧即
   `br·ea + dr·da·(1-ea)`）。再乘一次 alpha 把半透明内容压暗到 `outA` 倍。
   探针实测：单层 `(128,0,0,128)` 合成后变 `(128,64,0,0)`。
   → 改为 `qBound(0, mixR, 1.0) * 255.0`，附完整推导注释。

两条都是"数学看着对、结果全错"的形态，且**不在新写的代码里**，是踩到公用路径才暴露。

## ★ 反直觉实测（写进铁律 12.5）★

1. `QImage::fill(QColor)` **不做预乘**：`fill(QColor(128,0,0,128))` 后位图原始字节就是
   `(128,0,0,128)`，不是预乘后的 `(64,0,0,128)`。写像素断言时**别按直觉乘**。
2. `QColor(QRgb)` 构造函数**丢 alpha**（置 255）→ 取色/比对必须用 `QColor(r,g,b,a)` 四参版。

## 判据分家（写进铁律 12.3）

油漆桶取**活动图层**（`layer->image()`），吸管取**合成图**（`Document::composite()`）——
二者相反且各有道理：油漆桶要"在**这一层**上哪些像素同区域"，吸管要"所见即所得"。

## ★ 与计划的三处不同（写进架构规划「实现说明」）★

1. **取 alpha 通道，不 `convertToFormat(Grayscale8)`**：后者可能先反预乘，
   把抗锯齿边缘的"半透明白"还原成"不透明白"→ 蒙版边缘全是 255，**抗锯齿静默失效**。
   这与 §1.1「查表前要先反预乘」是同一硬币两面（那里该做没做、这里不该做却被动做了）。
2. **拖动预览必须幂等**：落笔取整层快照，每次重算都从快照出发；在上一帧结果上继续画
   会**累加**（手停在原地多抖动几次颜色就越来越深）。
3. **重算区域 = 上一帧包围盒 ∪ 本帧包围盒**：只取本帧会留残影
   （矩形从左上拖到右下，左上那块旧框没被覆盖回去）。

## ★ 本批回出的真 bug：直线漏了"零面积不画" ★

`rasterizeLine` 两点重合时，圆头笔帽画出实心小圆点 → 白底上**点一下就留红点**、
还压一条撤销记录。矩形/椭圆早已实现"零面积不画"，**只有直线漏了**。
修法：`|Δx|<0.5 且 |Δy|<0.5 → 返回空蒙版`，并在自检 [2] 补一条钉住。
教训：**同一条产品规则要写进每一处它适用的地方**——漏一处就是"只有用户点得出来"的 bug。
